Tóm tắt các bước triển khai WordPress với CloudFront

Tóm tắt các bước triển khai WordPress trên AWS Cloud với CloudFront

Dưới đây là tóm tắt toàn bộ quy trình triển khai WordPress từ đầu đến khi hoàn thành CloudFront:

1. Giới thiệu và Chuẩn bị

  • Mục tiêu: Triển khai WordPress với Auto Scaling Group, Load Balancer và CloudFront
  • Kiến trúc: WordPress trên EC2 (public subnet) + RDS MySQL (private subnet) + Multi-AZ + CDN

2. Các bước chuẩn bị hạ tầng

2.1 Tạo VPC và Subnet

  • Tạo VPC với CIDR block phù hợp
  • Tạo Public Subnet cho EC2 instances
  • Tạo Private Subnet cho RDS database
  • Cấu hình Internet Gateway và Route Tables

2.2 Tạo Security Groups

  • Security Group cho EC2: Cho phép HTTP (80), HTTPS (443), SSH (22)
  • Security Group cho Database: Cho phép MySQL (3306) từ EC2 Security Group

2.3 Khởi tạo EC2 Instance

  • Tạo EC2 instance trên Public Subnet
  • Cấu hình Key Pair để SSH
  • Gán Security Group cho EC2

2.4 Khởi tạo RDS Database

  • Tạo RDS MySQL instance trên Private Subnet
  • Cấu hình Multi-AZ deployment
  • Thiết lập database name: awsuser, username: admin, password: dbpassword

3. Cài đặt WordPress trên EC2

3.1 Cài đặt môi trường LAMP

# Cập nhật hệ thống
sudo dnf upgrade -y

# Cài đặt Apache HTTP Server
sudo dnf install -y httpd

# Cài đặt PHP và PHP-MySQL
sudo dnf install -y php-mysqli php

# Khởi động Apache
sudo systemctl enable httpd --now

3.2 Cấu hình quyền và tải WordPress

# Di chuyển đến thư mục web
cd /var/www/html/

# Cấp quyền cho Apache
sudo chown -R apache:apache /var/www/html
sudo chmod -R 755 /var/www/html

# Tạo file health check
echo "OK" | sudo tee /var/www/html/health

# Tải và giải nén WordPress
sudo wget https://wordpress.org/latest.tar.gz
sudo tar -xzf latest.tar.gz

3.3 Cấu hình WordPress

  • Truy cập http://<EC2-Public-IP>/wordpress/wp-admin/setup-config.php
  • Nhập thông tin database:
    • Database Name: awsuser
    • Username: admin
    • Password: dbpassword
    • Database Host: <RDS-Endpoint>
  • Tạo file wp-config.php với cấu hình được tạo

4. Thiết lập Auto Scaling Group

4.1 Tạo AMI từ EC2 Instance

  • Tạo Amazon Machine Image từ EC2 instance đã cài WordPress
  • AMI này sẽ được sử dụng làm template cho Auto Scaling

4.2 Tạo Launch Template

  • Tạo Launch Template sử dụng AMI vừa tạo
  • Cấu hình instance type, security groups, key pair

4.3 Tạo Target Group

  • Tạo Target Group cho Load Balancer
  • Cấu hình health check path: /health

4.4 Tạo Application Load Balancer

  • Tạo ALB trên các Public Subnets
  • Cấu hình listener cho HTTP (port 80)
  • Gán Target Group đã tạo

4.5 Tạo Auto Scaling Group

  • Tạo ASG sử dụng Launch Template
  • Cấu hình min/max/desired capacity
  • Gán Target Group của Load Balancer

5. Sao lưu và Phục hồi Database

5.1 Tạo DB Snapshot

  • Tạo manual snapshot cho RDS instance
  • Snapshot này dùng để backup và restore khi cần

5.2 Restore từ Snapshot

  • Thực hiện restore database từ snapshot khi cần thiết
  • Đảm bảo tính sẵn sàng của dữ liệu

6. Thiết lập CloudFront CDN

6.1 Tạo CloudFront Distribution

  • Truy cập AWS CloudFront console
  • Tạo Distribution mới với tên Webserver
  • Cấu hình Origin là Application Load Balancer
  • Chờ khoảng 5 phút để Distribution được deploy

6.2 Cấu hình WordPress với CDN

  • Truy cập WordPress Admin Dashboard
  • Cài đặt plugin WP Faster Cache
  • Cấu hình CDN settings:
    • CDN URL: <CloudFront-Distribution-Domain>
    • Origin URL: <EC2-Public-DNS>

7. Kết quả đạt được

Sau khi hoàn thành tất cả các bước, bạn sẽ có:

✅ WordPress website chạy trên kiến trúc có khả năng mở rộng cao
✅ Auto Scaling Group tự động điều chỉnh số lượng instances theo tải
✅ Load Balancer phân phối tải đều giữa các instances
✅ RDS Multi-AZ đảm bảo tính sẵn sàng cao cho database
✅ CloudFront CDN tăng tốc độ truy cập website toàn cầu
✅ Backup strategy với DB snapshots để bảo vệ dữ liệu

8. Lưu ý quan trọng

  • Đảm bảo tất cả resources được tạo trong cùng một Region
  • Kiểm tra Security Groups để đảm bảo kết nối giữa các components
  • Monitor CloudWatch metrics để theo dõi hiệu suất
  • Thực hiện backup database định kỳ
  • Cấu hình SSL/TLS certificate cho HTTPS (khuyến nghị)

Kiến trúc này đảm bảo website WordPress của bạn có khả năng chịu tải cao, tự động mở rộng theo nhu cầu và có hiệu suất tối ưu nhờ CDN CloudFront.
